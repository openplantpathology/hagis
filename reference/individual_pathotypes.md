# Prints Individual Pathotypes for Each Sample

Print an object from a `hagis.diversities` object with individual
pathotypes, *i.e.* each sample's pathotype. The resulting object is a
[pander](https://CRAN.R-project.org/package=pander) table (a text object
for Markdown) for ease of use in reporting and viewing in the console.

## Usage

``` r
individual_pathotypes(x, ...)
```

## Arguments

- x:

  a `hagis.diversities` object generated by
  [`calculate_diversities()`](https://openplantpathology.github.io/hagis/reference/calculate_diversities.md)

- ...:

  other arguments passed to
  [`pander::panderOptions()`](https://rdrr.io/pkg/pander/man/panderOptions.html)

## Value

A [`pander::pander()`](https://rdrr.io/pkg/pander/man/pander.html)
object of individual pathotypes

## See also

[`calculate_diversities()`](https://openplantpathology.github.io/hagis/reference/calculate_diversities.md),
[`diversities_table()`](https://openplantpathology.github.io/hagis/reference/diversities_table.md)

## Examples

``` r
if (FALSE) { # interactive()
# Using the built-in data set, P_sojae_survey
data(P_sojae_survey)

P_sojae_survey

# calculate susceptibilities with a 60 % cutoff value
diversities <- calculate_diversities(
  x = P_sojae_survey,
  cutoff = 60,
  control = "susceptible",
  sample = "Isolate",
  gene = "Rps",
  perc_susc = "perc.susc"
)

# print the diversities table
individual_pathotypes(diversities)
}
```
