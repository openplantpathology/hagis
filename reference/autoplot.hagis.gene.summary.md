# Plot hagis Summary Objects

Creates a [ggplot2](https://CRAN.R-project.org/package=ggplot2) object
of the gene summaries calculated by
[`summarize_gene()`](https://openplantpathology.github.io/hagis/reference/summarize_gene.md)

## Usage

``` r
# S3 method for class 'hagis.gene.summary'
autoplot(object, type, color = NULL, order = NULL, ...)
```

## Arguments

- object:

  a `hagis.gene.summary` object generated by
  [`summarize_gene()`](https://openplantpathology.github.io/hagis/reference/summarize_gene.md).
  `Character`.

- type:

  a vector of values for which the bar plot is desired. Specify whether
  to return a graph of the percent pathogenic isolates, `percentage`, or
  as the count, `count`. `Character`.

- color:

  a named or hexadecimal color value to use for the bar color

- order:

  sort the x-axis of the bar chart by ascending or descending order of
  `N_virulent_isolates` or `percent_pathogenic`. Accepts `ascending` or
  `descending` input values. Defaults to `gene` name. `Character`.

- ...:

  passed to the chosen `geom(s)`

## Value

A [ggplot2](https://CRAN.R-project.org/package=ggplot2) plot

## Examples

``` r
if (FALSE) { # interactive()
# Using the built-in data set, `P_sojae_survey`
data(P_sojae_survey)

# calculate susceptibilities with a 60 % cutoff value
susc <- summarize_gene(
  x = P_sojae_survey,
  cutoff = 60,
  control = "susceptible",
  sample = "Isolate",
  gene = "Rps",
  perc_susc = "perc.susc"
)

# Visualize the summary of genes
autoplot(susc, type = "percentage")
}
```
