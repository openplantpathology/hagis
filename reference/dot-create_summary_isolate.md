# Create Summary Table of Binary Reactions by Sample

Tally a summary by sample or isolate. This code takes the
"Susceptible.1" column and summarises it by gene for your total
"Isolates" pathogenic on each sample.

## Usage

``` r
.create_summary_isolate(.y)
```

## Arguments

- x:

  A [hagis](https://CRAN.R-project.org/package=hagis) `complexities`
  object generated by
  [`calculate_complexities()`](https://openplantpathology.github.io/hagis/reference/calculate_complexities.md).
  `Character`.

## Value

A `data.table` that tallies the results by sample.
